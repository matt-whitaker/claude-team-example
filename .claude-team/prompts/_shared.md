## This repository

An example consumer of claude-team, and its live drill target. Nothing here ships anywhere.

- **The gate is `true`.** There is no build, no lint, no tests — a run that edits a file has
  passed the gate by editing it.
- Treat every issue as a drill unless it says otherwise. Real-sounding work filed here is
  practice, not product.
- Keep your report short. The humans reading this repo are here to see the machinery's shape,
  not the prose.
